# sitetree-import-export

Import and export SilverStripe `SiteTree` content.

## Requirements

* PHP ^8.3
* silverstripe/framework ^6
* silverstripe/cms ^6

## Installation

```
composer require madecurious/sitetree-import-export
```

## Status

Scaffold only — functionality not yet implemented.
